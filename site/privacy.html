Privacy

Publisher: sigmasd · Last updated: 24 November 2026

Tandem has no account, no server of ours, no advertising and no analytics. Your files go only to the devices you paired, directly, over your own network.

Your files

During a sync, files are sent straight from one of your devices to the other, encrypted with a key the two devices made when they were paired. Nothing passes through a server, ours or anyone's. Tandem only reaches the folders you chose, and only a device you shared a folder with can ask for it.

What Tandem says on your network

While it is open, Tandem announces itself on the local network every few seconds, so your other devices can find it without typing an address: this device's name, a random identifier, the port it listens on, and whether it is showing a pairing code. Other devices on the same network can see that announcement. It carries no file names, no files and no secret.

What it keeps on the device

  • Its settings: this device's name, the paired devices and their keys, the folders you chose.
  • A list of each folder's files (names, sizes, dates, checksums), to tell what changed between syncs.
  • Old versions of replaced or deleted files, inside the folder (.tandem/old/), for 90 days by default.

All of it stays on the device. Removing a folder from Tandem, or uninstalling it, leaves your files where they are.

Updates

The desktop app checks GitHub for a new version when it starts and once a day, by downloading the release list from github.com, which sees that request like any visit. The Android app doesn't check for updates.

Permissions on Android

"All files access" lets Tandem read and write the folders you choose. The camera is only used to scan a pairing QR code, on that screen. Local network access finds and reaches your other devices.

This website

This site is hosted on GitHub Pages. It has no analytics or advertising. To show the download buttons, your browser asks GitHub's API for the latest release. GitHub may process ordinary request data under its own privacy terms.

Contact

Questions and problems: github.com/sigmaSd/tandem/issues. Please don't put private files or personal data in a public issue.
