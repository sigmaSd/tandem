## Preparing for F-Droid

This release changes how the Android app is built, so that F-Droid can build it from source. Nothing changes in the app itself.

**Correction (25 November 2026):** these notes first said that F-Droid's build matches this release's Android app byte for byte. It doesn't yet: one file, Node for Android (which runs Tandem on the phone), still differs between the two builds. A fix is being tested for a later release.
