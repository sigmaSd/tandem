## Tandem is free software

Tandem is now under the [GPL 3.0 or later](https://github.com/sigmaSd/tandem/blob/main/LICENSE): use it, study it, change it and share it. The name and the icon stay Tandem's own: a modified version shared with others goes under another name.

## On the phone

- Comparing two versions no longer offers to open them in another app, which the phone can't do yet.

## On its way to F-Droid

The Android app is now built the same way anywhere: from the same sources, any machine makes the very same APK. That lets F-Droid build Tandem from source and still ship this exact APK, signed by Tandem: once Tandem is on F-Droid, you can move between F-Droid and these downloads without reinstalling.
