## Preparing for F-Droid

This release changes how the Android app is signed, so that F-Droid can ship the app it builds from source with the same signature as here. Nothing changes in the app itself, on the phone or on computers.

On the phone it updates 0.3.9. **Coming from 0.3.8 or older on Android?** The app has a new identity since 0.3.9, so it installs next to the old one: read [what to do first](https://github.com/sigmaSd/tandem/releases/tag/v0.3.9).
